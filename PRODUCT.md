# Product

## Register

product

## Users
One operator (the builder) using it daily and demoing it to others. They upload their own PDF books, ask questions, plan trips, and want to see how the multi-agent graph routed and answered each request.

## Product Purpose
Guide AI: a personal assistant over a multi-agent backend: a classifier routes each message to a book-lookup (vector search + Neo4j recommendations), travel (MCP tools), Google Workspace, or casual-chat agent, and streams the answer. Success: questions get answered from the user's own library, and the routing is visible without getting in the way.

## Brand Personality
Calm, literate, precise. Quiet like a reading room; the library is the soul of the product. Agent activity is shown as marginalia beside answers, never as a dashboard.

## Anti-references
- Generic AI chat clones (ChatGPT-style centered column with gradient sparkles).
- SaaS dashboard kit: identical rounded cards, hero metrics, soft gray shadows.
- "Hacker terminal" dark mode with neon accents.
- Cream-paper-and-terracotta "editorial AI" default.

## Design Principles
1. The answer first; the agent's reasoning as marginalia.
2. The library is a place, not a settings page.
3. Show routing honestly: which agent, what it retrieved, what it recommended.
4. Earned familiarity: standard affordances, no reinvented controls.
5. Every state is designed: empty, streaming, failed, offline backend.

## Accessibility & Inclusion
WCAG 2.2 AA. Full keyboard use, visible focus, reduced motion respected, streaming text announced politely, contrast verified in both themes.
